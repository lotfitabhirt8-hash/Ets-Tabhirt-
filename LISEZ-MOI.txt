Publication gratuite avec GitHub Pages :
1. Créez un compte sur https://github.com/
2. Créez un dépôt public nommé ets-tabhirt.
3. Téléversez index.html et logo-ets-tabhirt.jpg à la racine du dépôt.
4. Ouvrez Settings > Pages.
5. Choisissez Deploy from a branch, branche main, dossier / (root), puis Save.
6. GitHub affichera l'adresse publique du site.

Les photos d'illustration du site nécessitent une connexion Internet.
